# MAYA SWIM — אתר תדמית לבגדי ים

אתר סטטי (HTML, CSS ו-JavaScript בלי ספריות), דו-לשוני (עברית ואנגלית), שמוכן לעלות ל-GitHub Pages ולהתחבר לדומיין שקנית ב-Wix.

## מה יש בתיקייה

```
maya-swim/
├── index.html            דף הנחיתה
├── accessibility.html    הצהרת נגישות (תבנית למילוי)
├── privacy.html          מדיניות פרטיות (תבנית למילוי)
├── 404.html              דף "לא נמצא"
├── .nojekyll             אומר ל-GitHub Pages להגיש את הקבצים כמו שהם
└── assets/
    ├── css/style.css     כל העיצוב (צבעים בראש הקובץ, תחת :root)
    ├── js/config.js      ← הקובץ שעורכים: פרטי קשר, קולקציה, טבלת מידות
    ├── js/i18n.js        כל הטקסטים באתר, בעברית ובאנגלית
    ├── js/main.js        הלוגיקה (שפה, חלון פרטים, מחשבון מידה, טפסים, נגישות)
    ├── fonts/            הגופנים Frank Ruhl Libre ו-Assistant (מאוחסנים מקומית)
    └── img/              לוגו, אייקון, תמונת שיתוף, ואיורי העיצובים
```

## מה האתר כולל

- **דף נחיתה מלא:** פתיח, קולקציה עם סינון (ביקיני / בגד ים שלם) וחלון פרטים לכל דגם, "למה מהדורות מוגבלות", הסיפור של המותג, תהליך העבודה, ארבע דרכים להתקדם (הזמנה אישית, עדכונים, שיתופי פעולה, אינסטגרם), מדריך מידות עם מחשבון, שאלות נפוצות, הרשמה לעדכונים וטופס יצירת קשר.
- **עברית ואנגלית:** כפתור EN / עב בראש העמוד. הבחירה נשמרת, ואפשר גם לשלוח קישור ישיר לאנגלית: `?lang=en`.
- **וואטסאפ:** כל כפתור פותח שיחה עם הודעה מוכנה (כולל שם הדגם, כשלוחצים מתוך דגם מסוים).
- **נגישות:** ניווט מקלדת, קישור דילוג, תוויות לטפסים, תמיכה ב"הפחתת תנועה", ותפריט נגישות (גודל טקסט, ניגודיות גבוהה, הדגשת קישורים, גופן קריא, עצירת אנימציות).
- **פרטיות:** בלי עוגיות, בלי כלי מעקב, והגופנים נטענים מהאתר עצמו ולא מגוגל.

## לפני שמעלים לאוויר — צ'קליסט

1. **`assets/js/config.js`**
   - `whatsapp`: מספר בפורמט בינלאומי. לדוגמה `0521234567` הופך ל-`972521234567`.
   - `email`, `instagram`: הכתובת ושם המשתמש האמיתיים.
   - `designs`: שמות, תיאורים, בדים וכמויות. **כל מה שכתוב שם עכשיו הוא טקסט לדוגמה.**
   - `sizes`: טבלת המידות. הערכים הם טבלה כללית; עדכנו לפי הגזרות שלכם.
2. **טקסטים:** הסיפור, השאלות הנפוצות וכל השאר נמצאים ב-`assets/js/i18n.js` (עברית למעלה, אנגלית למטה). הטקסט ב-`index.html` הוא רק גיבוי למקרה ש-JavaScript כבוי, אז כדאי לעדכן גם שם את מה ששיניתם.
3. **הצהרת נגישות ומדיניות פרטיות:** מלאו את כל מה שמופיע ב-[סוגריים מרובעים] (שם, טלפון, תאריך, שם העסק). אלה תבניות, לא ייעוץ משפטי; מומלץ שעורך/ת דין ומורשה/ית נגישות יעברו עליהן.
4. **תמונות:** כשיהיו צילומים אמיתיים, שמרו אותם ב-`assets/img/designs/` (יחס 4:5, לפחות 800×1000 פיקסלים, בפורמט jpg או webp), ועדכנו את השדה `image` בכל דגם ב-`config.js`. אחר כך שנו בקובץ `i18n.js` את `card.alt` כך שיתאר צילום ולא איור.
5. **תמונת שיתוף:** אחרי שהדומיין מחובר, שנו ב-`index.html` את `og:image` לכתובת מלאה, למשל `https://הדומיין-שלכם/assets/img/og-image.png`.

## טופס יצירת קשר והרשמה לעדכונים

אתר ב-GitHub Pages לא יכול לשלוח מיילים לבד. כל עוד לא הגדרתם שירות טפסים, לחיצה על "שליחה" פותחת את תוכנת המייל של המבקרת עם ההודעה מוכנה.

כדי שהפניות יגיעו ישר למייל שלכם:
1. פתחו חשבון חינמי ב-[Formspree](https://formspree.io) וצרו טופס חדש.
2. העתיקו את כתובת ה-endpoint (נראית כמו `https://formspree.io/f/abcdwxyz`).
3. הדביקו אותה ב-`config.js` בשדה `formEndpoint`. אם תרצו טופס נפרד להרשמה לעדכונים, הדביקו כתובת שנייה ב-`newsletterEndpoint`.

הטפסים כבר כוללים שדה נגד ספאם (`_gotcha`), כותרת למייל (`_subject`) ותיבת הסכמה.

## העלאה ל-GitHub Pages

הריפוזיטורי כבר קיים: `itaytoren7/maya_swim`, והקבצים יושבים בשורש שלו (כולל `.nojekyll`).

1. דוחפים את השינויים לענף `main`:
   ```bash
   git add -A
   git commit -m "עדכון האתר"
   git push origin main
   ```
2. פעם ראשונה בלבד: בריפוזיטורי **Settings → Pages → Build and deployment**, בחרו **Deploy from a branch**, ענף `main` ותיקייה `/ (root)`, ושמרו.
3. אחרי דקה-שתיים האתר יעלה בכתובת `https://itaytoren7.github.io/maya_swim/`.

## חיבור הדומיין מ-Wix

1. ב-GitHub: **Settings → Pages → Custom domain**, הקלידו את הדומיין (למשל `mayaswim.co.il`) ולחצו Save. GitHub ייצור בריפו קובץ `CNAME`.
2. ב-Wix: **Domains** ← אייקון הפעולות ליד הדומיין ← **Manage DNS Records**.
3. ב-**A (Host)**, הוסיפו ארבע רשומות לדומיין הראשי (`@`), אחת לכל כתובת:
   ```
   185.199.108.153
   185.199.109.153
   185.199.110.153
   185.199.111.153
   ```
   ומחקו את רשומות ה-A הישנות שהצביעו ל-Wix.
4. ב-**CNAME (Aliases)**, הגדירו ש-`www` מצביע ל-`USERNAME.github.io`, ומחקו CNAME ישן של `www` אם יש.
5. חכו לעדכון ה-DNS (זה יכול לקחת עד 24–48 שעות), ואז ב-GitHub Pages סמנו **Enforce HTTPS**.

## בדיקות מומלצות לפני השקה

- לעבור על כל האתר רק עם המקלדת (Tab, Shift+Tab, Enter, Esc).

- לבדוק בטלפון, בעברית ובאנגלית.
- לשלוח פנייה אמיתית מהטופס ולוודא שהיא מגיעה.
